> 状态（2026-10-11）：软件侧全部就绪并已部署到板（robotd I²C IMU 来源 + 容错启动 + 中控适配），

## 0. 已就绪、无需再动的部分

- 板上 robotd（I²C LSM6DSV16X @0x6b、`/dev/i2c-pihat`）：上电自启，IMU 数据 46Hz 实时，
  中控 IMU 页正常显示。systemd drop-in `zzzz-i2c-imu.conf` 已放行 i²c 设备。
- 舵机总线容错：舵机不在线时 IMU 独立运行（phase `servo_read_error`）；舵机一旦应答，
  约 100ms 内自动补做扭矩确认并转 `ready`，**无需重启 robotd**。
- 待办（用户侧，一次性）：重启一次中控 `console.py`，重新输入机器人密码——来源标签变
  「I²C LSM6DSV16X」，状态徽标 live，陀螺/四元数读数点亮。

## 2. 接线（全部断电，接完万用表蜂鸣档复查）

1. 15 颗舵机 → HAT 舵机口（ID 对应关系见 §3，先不贴标也可以，标定前逐颗核对）。
2. 2S 电池（7.4V，HD-1910 窗口 4–8.4V）→ HAT 电池口；**保险丝 3~5A（台架）**。
3. Radxa 保持现有供电（USB-C 等），**不取 HAT 上的电**。
4. IMU 继续留在 40-pin I²C（3/5 脚 + 3.3V + GND）不动，与 HAT 无冲突。
5. 共地检查：电池负极、HAT、Radxa、IMU 之间 GND 导通。
6. ⚠️ 严禁 7.4V 碰 Radxa 的任何引脚。

## 3. 上电与舵机 ID 核对

1. Radxa 上电 → 等一分钟后舵机电源上电（顺序随意，robotd 会自动发现）。
2. SSH 检查：`robotctl health` → phase 应为 `ready`，`robotctl` 或中控舵机诊断页应列出
   **15 颗全部在线**（ID：左腿 20–24、头部 30–34、右腿 10–14）。
3. 若有舵机不在线或 ID 不对：该颗舵机从 HAT 拔下，单独接
   （用 studio「URT2 调试台」或 HAT 单口；接线与只读探针流程见
   [URT2 + HD-1910 指南](URT2-HD1910接线组装与测试指南.md)），出厂 ID1@1Mbps
   （规格书默认；不通再试 57600 等低档）→ 改写为官方 ID → REBOOT →
   新 ID 验证 → 贴标。**一次只接一只。**
4. ID 速查与位置对照：`microduck-servo-guide` 3D 页（左腿 20–24，右腿 10–14，站机器人
   背后同向看）。

## 4. 关节标定（中控「关节标定」面板）

1. 面板显示 phase `ready`、扭矩 off、按钮解锁。
2. RELAX 卸力 → 支撑机身 → 手动摆位 → 逐关节 **capture**（记录 zero_raw 与方向 ±1）。
   注意：2048 居中不是装配零位，以实际摆位为准。
3. 缓慢驱动到机械限位两端，量取并填 `min_rad` / `max_rad`。
4. 保存 → 写入 `/etc/robot/feetech-ft5/hd1910-calibration.toml`
   （训练台之后会拉同一份烘进仿真，一处标定三端一致）。

## 5. 红线（标定阶段不做的事）

- **verify-imu 先不点**：LSM6DSV16X 模块需先刚性固定到躯干，再按五阶段做安装方向核对
  （正立重力 ≈ [0,0,-1]、翻转/低头符号、±90° 四元数无跳变），之后才确认
  `imu_mount_verified`。完整核验步骤与两条 IMU 路径（I²C 直读 / imu_to_dxl 桥）见
  [IMU 集成教程](IMU集成教程-I2C直读与imu_to_dxl.md)。
- **motion_enabled 保持 false**：15 关节全部 capture + IMU 安装确认 + 舵机↔IMU 联合核对
  （FK 姿态与 IMU 对齐 <±2°）全部完成前不开运动。逐颗摆位标定也可以用社区
  hls_servo_debugger 网页调试器（已部署于核心板 `/opt/hls_servo_debugger`，
  `systemctl stop robotd` 后启动，浏览器操作），流程见
  [microduck-community-kit 使用教程](microduck-community-kit使用教程.md)。
- 总线同一时刻只允许一个主站：中控标定时 robotd 独占总线，studio 的 URT2 调试台不要
  同时连。
