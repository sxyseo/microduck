# 低成本舵机替换决策表

目标不是“买最便宜的舵机”，而是让每个关节在满足扭矩、速度、供电、结构和安全要求的前提下，
使用成本最低的执行器。没有完成台架测试前，候选件只能标为“待验证”，不能直接装整机或加载 ONNX。

## 1. HL-2915 是基准，不是所有候选件的直接替代

当前基准：HL-2915-C001，典型 12V，约 34×20×23mm，位置范围 0–4095，使用 Feetech 半双工串行协议。
候选件即使也写着“总线舵机”或“4096 分辨率”，协议、寄存器地址、反馈项目和电压仍可能不同。

仓库提供了一个只读的采购前筛选器，可把候选型号规格书整理成 JSON 后运行：

```bash
python tools/microduck_learning/check_servo_candidate.py candidate.json \
  --json-out artifacts/servo-candidate-report.json
```

它只输出资料层面的分类，不会把候选件标成“已通过”：`hardware_passed` 永远为 `false`，
直到你完成单只样品通信、10 分钟 CSV、结构和动力学实验。缺字段会得到
`insufficient_data`；协议不同会得到 `new_bus_driver`；6V/低扭矩候选通常会得到
`low_load_power_variant`，只能作为嘴部或头部等低负载实验方向。

### 2.1 当前推荐的省钱试验顺序

先不要替换腿部舵机。最现实的成本实验是：

1. HL-2915 保留给髋、膝、踝等高负载关节；
2. 只买 1 只 ST-3032-C001 或 ST-3032-C036，先做嘴部/头部台架；
3. 用同一只读探针确认它的 ID、波特率、寄存器地址和状态字；
4. 如果协议包相同但地址不同，新增型号 profile；
5. 如果电源和结构通过，再考虑批量替换低负载关节；
6. 腿部候选必须先测实际扭矩、电流和温升，不能按“4.5kg.cm”直接推断能站立。

这条路线可以把“省钱”限制在低风险关节，不会因为一次采购错误导致 15 个关节全部返工。

## 3. 驱动复用等级

### A 级：可尝试复用当前 HL-2915 驱动

候选件必须同时满足：

- 12V 供电范围包含当前电源；
- Feetech 半双工 TTL 协议版本一致；
- ID、波特率、PING、READ、WRITE、SYNC_READ、SYNC_WRITE 行为一致；
- 位置为 12-bit（0–4095）；
- 位置、速度、负载、电压、温度和电流地址已经从该型号内存表确认；
- 机械安装和输出花键可以适配。

即使满足这些条件，也要重新做零位、方向、速度单位、电流单位和 PID 标定。

### B 级：复用协议，但新建型号 profile

如果包格式相同，但寄存器地址、速度单位、电流单位或 PID 地址不同，就复用半双工通信层，
但必须增加新的型号 profile。不能把 HL-2915 的地址表硬编码套过去。

### C 级：新总线驱动

RS485、CAN、Modbus-RTU、Dynamixel Protocol 2 都属于新总线或新协议路线，需要：

- 新收发器；
- 新协议实现；
- 新故障和超时处理；
- 新电源/线束验证；
- 新动作延迟和动力学数据。

### D 级：普通 PWM 舵机

普通 PWM 舵机不能直接接入当前总线驱动。必须增加 PWM 控制板，并解决位置反馈、电流/温度监测、
同步采样和安全停机问题。它通常不是这个项目的低风险降成本路线。

## 4. 每个候选件必须通过的实验

不要一次购买 15 只。每个候选型号先买 1–2 只，按下面顺序验收：

1. **资料关卡**：保存规格书、协议手册、内存表、连接器线序和实物照片。
2. **电源关卡**：使用该型号额定电压，测空载、启动和堵转保护电流；不得用 12V 猜测 6V/7.4V 舵机。
3. **通信关卡**：单只 Ping、读位置、读电压/温度、改 ID；记录实际波特率和响应包。
4. **连续关卡**：至少 10 分钟只读，保存位置、速度、负载、电流（若有）、电压和温度 CSV。
5. **阶跃关卡**：空载小角度正反向阶跃，测延迟、回差、超调、停稳时间和真实速度。
6. **结构关卡**：测安装孔、外壳包络、输出花键、舵盘偏心和关节可动范围。
7. **关节关卡**：只装一个低风险关节，悬空低速运行，检查机械干涉和温升。
8. **模型关卡**：只有测完动力学，才修改 MJCF/BAM；执行器改变后重新训练，不复用旧 ONNX。

每一步都要保留原始数据和失败记录。没有 CSV 或协议手册的候选件，不进入下一关。

## 5. 最可能的降成本策略

1. 先用 HL-2915 跑通通信、IMU、HAT、相机和控制循环。
2. 统计每个关节的实际峰值电流、扭矩需求、速度和温升。
3. 只在嘴部、头部等低负载关节尝试 6V/低扭矩候选件。
4. 如果低压候选件需要独立电源，先画出电源树和共地方案，再改结构。
5. 只有候选件在单关节和单腿实验中通过，才考虑批量替换。
6. 批量替换后重新辨识 BAM，并重新训练和验证 ONNX。

“协议相同”只能省掉一部分软件工作，不能省掉电源、结构和模型验证。
