# 解读 179 · 端到端推演:换成 STS3215

> **解读对象**:`bam/bam/params/feetech_sts3215_7_4V/m6.json` + 换舵机方法论([解读 73](73-换舵机决策树.md)–[84](84-案例复盘HL1910到HL2915.md))
> **需要的前置**:[解读 79](79-参数适配五落点.md)(训练侧五个落点)· [解读 85](85-电压全景.md)(三代舵机电压窗)

这是方法论(73–84 课)的第一次实弹演习:把 Microduck 的 15 只 XL330 换成飞特 STS3215——
单价约 ¥60–70(约 XL330 的 1/5),力矩还更大(1.86 N·m vs XL330 仿真限 0.96 N·m,厂商标称口径见选型文档)。看起来是送分题,
推演完你会发现它是一道"换机器人"题。

## 1. 机械:重量预算第一秒就爆

STS3215 约 55–60 g,是 18 g XL330 的三倍多。15 只合计多出约 **585 g**——737 g 的鸭子
背上 585 g 纯增重,重心、关节力矩需求、结构强度全部推倒。而且 XL330 的舵机腔按实测
29×20×34 mm 挖出,M2 孔位是照 XL330 反推的,STS3215 大一档,**塞不进去**——打印件全部
重画。这推演不用猜:同一工程师的 Open Duck Mini v2 就是"STS3215 版答案"——整机做成
42 cm、2107.1 g,是 Microduck 的 2.86 倍。

## 2. 电气:7.4 V 撞上 2S 母线

BAM 库里这颗是 7.4 V 版(目录名 `feetech_sts3215_7_4V`,actuator 类 `vin=7.4`)。
官方电压窗口宽窄未在本仓核对,**待验证**;Microduck 的 2S 母线是 6.6–8.2 V(满电 8.4 V),
直接挂上大概率超压。保守改法:加一级 buck 降到 7.4 V 级(85–91 课套路);
插头、线序按 [解读 76](76-电气适配.md) 核对。`_BAM_ACTUATOR_KWARGS` 里的
`vin_range=(6.5, 8.2)` 是 XL330 超压特例,**绝不能照抄**,要按你实测的窗口重填。

## 3. 协议:最顺的一环

STS3215 走飞特 STS 半双工 TTL 协议——与项目已选的 HL-1910/HL-2915 是同门,
寄存器思路([解读 64](64-磁编码协议.md))通用。更好的消息在选型文档里:Open Duck Mini 用
`rustypot.feetech(port, 1000000)`——同一个 rustypot 库换协议模块,波特率同样 1 Mbps,
通信层"换模块"而不是"重写"。固件行为也别忽略:BAM 的 `STS3215Actuator` 是 stateful 的——
固件对目标位置做限速(`max_velocity≈5.096 rad/s`)再进 P 控制器(kp=32、`error_gain=0.166`),
仿真里不复现这个限速,阶跃响应就对不上。

## 4. 参数与重训:五落点逐个落

[解读 79](79-参数适配五落点.md) 的五个落点,对照 json 与 xl330 的真实数字:

| 落点 | STS3215 值 | 对比 xl330 |
|---|---|---|
| `motor_name` | `sts3215`(json `actuator` 键,目录名随意) | 改一处,三处同步 |
| 力矩常数 kt | 1.275 | 0.346 → **3.7 倍** |
| armature | 0.0216 | 0.0016 → **13.7 倍** |
| friction_base / viscous | 0.0533 / 0.0282 | 0.0119 / 0.0058 → **4.5 / 4.9 倍** |
| 独有字段 | `error_gain_ratio`=1.162 | xl330 没有 |
| `command_delay` | 0.0050 s | 0.0102 s——**反而短** |

延迟那条是个好提醒:0.0050 与 0.0102 是两颗舵机**两次台架**的实测,不能推广成
"飞特比 Dynamixel 快",只能填进自己那次辨识的结果。其余照 [解读 79](79-参数适配五落点.md):
回差角重测(ODMv2 建模 ±0.5°,XL330 是 ±1°)、MJCF 质量惯量全重算、域随机化范围按新台架
离散度重填;61 维观测、14 维动作、reward 结构**一律不动**。

## 5. 结论:官方 ONNX 全部作废,换来一只更大的鸭

执行器选型文档的原话:"这不是「换个舵机」,是「换一台机器人」。"五落点里机械最重、
电气次之、协议最轻。真要走通,答案是去做 Open Duck Mini v2(BOM、CAD、走路策略全套开源)
——保留的是 61/14 契约、台架六课、辨识流水线这套方法论。

## 你带走的收获

- 换 STS3215 的瓶颈按重量排序:机械(重 3 倍、腔体不装)> 电气(2S 超压)> 协议(同库换模块)。
- `sts3215` 的 m6.json 每项都比 xl330 "重"一个台阶:armature 13.7 倍、摩擦预算 4–5 倍。
- `vin_range` 是官方超压特例,不是公式;你的范围只能来自你的供电与台架实测。
- 单价 1/5 的诱惑要用整机成本结算:打印件全重画、策略全重训、机器人变成另一台。
