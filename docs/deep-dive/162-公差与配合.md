# 解读 162 · 公差与配合:测试片的数学

> **解读对象**:概念课 · 以 `microduck-replica/docs/打印工艺调整表.md`(§一至§三)+ `microduck-replica/构建日志.md`(尺寸与配合验证)为教材
> **需要的前置**:[解读 40](40-轴承与公差.md)过一遍即可;初中数学。

## 孔为什么会小

FDM 一层层堆塑料,水平方向的圆孔每一层都要"横跨"过去:桥接的材料冷却收缩,把孔拉小。调整表给的量级是 **0.1–0.3mm**——设计值 Ø2.2 的过孔,打出来只剩约 1.9–2.1mm,M2 柱头螺丝装不进。而全机 M2 孔位按打印数量加权共 186 个:过孔 ×111、沉头 ×48、攻丝底孔 ×27(打印就绪检查)。上游 STL 是仿真件,孔径全是设计值,它不管这些。

对策写在调整表 §一:切片器开"水平孔补偿 **+0.15~0.25mm**",或打印后用 Ø2.5 钻头过一下;攻丝底孔 Ø1.6 的 PLA 建议实值 **Ø1.65–1.75**(本项目是塑料自攻,不是金属丝锥);沉头 Ø4.4 基本免处理,装不进用 Ø4.5 钻头扩口。

## 60×40×4 的测试片:一张查出全部补偿值

补偿值不该拍脑袋。调整表的办法是先打一张 **60×40×4mm、约 30 分钟**的测试片,把全机用到的每一档孔都做成阶梯:

```text
过孔   Ø2.2 / 2.3 / 2.4 / 2.5    ← M2 螺丝"刚好能过"的那档,就是你的补偿值
攻丝   Ø1.6 / 1.65 / 1.7 / 1.75  ← 自攻"拧得进且不裂"的那档
沉头   Ø4.4 + Ø2.2 组合          ← 验证柱头能沉平
轴承   Ø21.9 / 22.0 / 22.1       ← 22×16×4 轴承(躯干/腿,全机 11 颗)
小轴承 Ø14.9 / 15.0 / 15.1       ← 15×10×3 轴承(头颈,3 颗)
```

判定只有两句:螺丝以**手指力量**顺畅通过 = 合格过孔;自攻拧入 **3 圈以上不裂不旷** = 合格底孔。轴承孔三档对应三种配合——**过盈**(压进去不出)、**过渡**(轻压入)、**间隙**(放进去会晃);轴承座的目标是"轻压入":多数 FDM 打 Ø21.9–22.0 再砂纸修,太松用微量胶固定。

## "整个复刻里最值钱的一行数据"

测试片的数学本质:补偿值不是孔的属性,是**你这台机器 + 这种材料 + 这组参数**的属性。所以调整表要求把实测值回填构建日志的"尺寸与配合验证"表,并称之为"整个复刻里最值钱的一行数据";同文再敲一次:换材料 = 重测。实物进度(构建日志):腿部件 M2 螺丝已实装、孔位反推正确,"但个别孔仍需钻孔修正(正常现象)"——反推几何与打印工艺是两码事。这张表到现在还空着,等的就是你打完测试片的那一行。

## 你带走的收获

- 公差靠量不靠猜:一张 30 分钟的测试片,定全机 186 个孔的补偿值。
- 配合三档(过盈/过渡/间隙)怎么选,取决于这对零件装上去还要不要拆、要不要转。
- 判定用"手指力量""拧入 3 圈"这类可操作语言,而不是"差不多"。
- 补偿值随机器、材料、参数变:同机同料同参数是它成立的前提。
- 个别孔钻修是正常现象;不把它记录下来才是失败。
