# 解读 144 · 万用表怎么用

> **解读对象**:概念课 · 以 `docs/HL-2915路线全流程教程.md` §5.2(验收电压)与 `docs/新手学习文档.md`(§7 第 4 阶段、§9 安全卡)为教材
> **需要的前置**:[解读 143](143-电是什么.md)(电压/电流/功率)、[解读 67](67-电力拓扑.md)(要量的是哪张电路)

上一篇讲了电的道理,这一篇讲工具。万用表是电气第一件仪器:几十块钱,回答"有电吗、多少伏、通没通"。本篇只教两件事——**量电压**与**查通断**(蜂鸣档展开在解读 145)。

## 认识它:两根表笔、一个档位盘

万用表长得像一个小方块收音机。下方几个插孔:黑表笔永远插 **COM**(公共端),红表笔插 **VΩ**(电压/电阻)孔;中间档位盘,转到哪就是哪把尺子。文字示意(通用样式):

```text
      ┌──────────────────────┐
      │   OFF ●────● V⎓      │  V⎓ 直流电压档:电池、舵机总线、UBEC
      │                      │  V~ 交流电压档:市电插座,本项目用不到
      │  Ω ♪(蜂鸣)  mA/A    │  Ω 电阻档;♪ 蜂鸣档(断电才许用!)
      │                      │  A 电流档:要串进电路,新手先跳过
      │ COM ⊖          ⊕ VΩ  │  A 档用错=短路烧表,原因见下
      └──────────────────────┘
```

新手只需三个档:`V⎓`、`♪`、`OFF`。用完转回 OFF,防止下次一搭表笔就打火。

## 量电压:三步 + 鸭子的三个数

一,转 `V⎓` 直流档(电池/舵机都是直流;V~ 交流档只会读出乱数)。二,量程大于预期:量 12V 选 20V 档。三,红笔探正、黑笔探负,**并联**搭上——表笔只是"趴在线路上看",不用剪断任何线;读反显示负号,不伤表。

用这三个数字练手,全部出自教程 §5.2 的验收:空载母线 **12.3–12.6V**(3S 满电附近;读数明显低,先怀疑电池没充满或表笔接触不良);UBEC 输出 **5.0–5.2V**(低了 Radxa 会莫名重启);给台架单只 XL330 供电时,供电端应在 2S 电压窗内(标称 7.4V,代码窗 6.6–8.2V)。`新手学习文档.md` §7 第 4 阶段把它列为总线舵机实验的第 3 步:"万用表测电源正负和空载电压"——**上电之前**先量一次,是整个项目第一条电气纪律。

## 动态电压:让舵机动起来再量

静态电压只是半个体检。教程 §5.2 的第二条验收是动态的:单舵机课做 3 个动作,**同时**盯着母线电压——压降 <0.5V 合格。操作上就是"表笔搭住母线正负极,另一只手触发动作":静置 12.4V,舵机发力瞬间掉到 12.1V 以内算健康;掉到 11V 级别说明电源内阻大,先换电源再查别的。这一步教会你 143 篇的压降概念怎么落地:电压不是常数,是"电流流出多少"的实时记录。

## 安全习惯:三条来自文档的铁律

其一,**断电用蜂鸣档,带电只许电压档**——教程 §5.2 的标题原话是"全部断电接线,接完用万用表蜂鸣档复查",顺序纪律写在标题里(蜂鸣档怎么用看解读 145)。其二,量压时表笔金属头别同时碰到相邻两个引脚:HL-2915 用 PH1.25-3P 插头(1=GND、2=Vcc、3=Signal,§12.1),间距只有约 1.25mm,镊子似的表笔一歪就是人为短路——可以先在插头延长线上量,或笔尖套热缩管只露一点点。其三,电流档(A)新手别碰:它内阻极低,并联搭上电路等于制造短路,多数烧表烧保险都发生在这一档;本项目要测电流时,靠电源的限流显示和保险丝选型(台架 5A)间接覆盖。加上 §9 安全卡的总则——改线前断电、伸手能碰到断电开关——你已经有了一套不烧板子的最小操作规程。

## 你带走的收获

- 黑表笔永远在 COM,档位先 `V⎓` 后量程大于预期;量电压是并联,不用断线。
- 三个必背读数:3S 母线 12.3–12.6V、UBEC 5.0–5.2V、动作压降 <0.5V。
- 上电量一次(静态),舵机动起来再量一次(动态)——压降才是电源体检的真指标。
- 蜂鸣档断电用、A 档新手跳过、细插头上表笔防搭错:三条习惯保住你的板子和表。
