# 解读 168 · 强度入门:材料失效

> **解读对象**:概念课 · 以 `microduck-replica/docs/打印工艺调整表.md` + `microduck-replica/BOM.md`(打印件表)+ `microduck-replica/docs/打印就绪检查.md` 为教材
> **需要的前置**:[解读 160](160-打印材料.md);[解读 36](36-腿部连杆.md)讲过"三明治"结构。

## 零件怎么"坏":文档里出现过的三种

结构件失效不都是"啪一声断成两截"(断裂模式分类属通用经验,项目文档未展开)。落到这只鸭子上,文档里真实出现的三种是:

- **变形**:塑料件被单边螺丝力拉翘、过度锁紧压伤——说明书注意事项原文"塑料件切勿过度锁紧";防御手法是"对角分步预紧"(解读 167)。
- **滑丝**:M2 自攻的螺纹靠塑料被挤出成型,拧到底硬怼就滑丝,**不可逆**(course/20)。新手文档 §6.2 提醒先想清楚"螺丝受的是拉力、剪切还是反复振动",以及"轴承是否承担了侧向载荷,而不是让舵机输出轴硬扛"——失效预防在设计阶段就开始。
- **薄壁抖纹**:薄板打印冷却不均产生振纹,这是精度层面的失效,不是一声脆响。

## 加固板:1.0mm 的答案

BOM 打印件表里有一件不起眼的东西:`upper_leg_rigidity_plate_上腿加固板` ×2。它有多薄?打印工艺调整表专门点名:"上腿加固板 **1.0mm** 薄、颈部 2.0mm"。1.0mm 的板单用毫无刚度,但解读 36 讲过大腿的读法:这是"平板 + 加固板"三明治——**抗弯刚度靠隔开距离的两片板,不靠板厚**;薄板把受力面撑开距离,大片开槽去掉中性层附近的材料,"刚度靠几何,不靠堆料"。

代价写在工艺表同一段:薄壁件要**冷却风扇全开 + 减速**防抖纹,加固板建议**立印**或加裙板。而"打印就绪检查"自曝边界:自动体检"**不包含**最小壁厚与悬垂分析——请在切片器里开「细墙/悬垂检测」过一遍"。薄壁是这 41 件里最需要人眼盯的强度风险。

## 材料与方向:失效模式是选出来的

- **材料**:结构件 299g PLA、软性件 26g TPU(软下巴/软嘴)。构建日志 09-06 认真评估过"PLA 顶 TPU"的代价:鸭嘴实为软夹爪,PLA 版会让叼取技能退化、连杆公差无弹性易卡——虽不影响走路/装配/发声,但"**勿让店家降填充冒充软料**"。选材料本质是选失效模式:你要它刚(结构件),还是要它让(接口件)。
- **方向**:调整表写明过孔类尽量孔轴垂直于打印平面摆放,并注明代价——"**牺牲强度换装配**"。为什么有牺牲?FDM 层层堆叠,层与层的结合弱于层内(此机理文档未展开,属通用经验——"层间撕裂/沿层断裂是 3D 打印件最常见失效之一"是文献通识,非本仓证据)。项目文档没写"层间"二字,但"牺牲强度换装配"这半句,就是承认了打印件的强度随方向变。

## 你带走的收获

- 失效三件套:变形、滑丝、薄壁抖纹——文档各给了一条真实防线。
- 1.0mm 加固板证明刚度问题可以用几何解决,不必加厚。
- 薄壁与悬垂不在自动体检范围,切片器的细墙/悬垂检测是必做的第二关。
- TPU 件别拿 PLA 顶:材料决定失效模式,公差弹性也是功能。
- "立印""孔轴垂直"这些摆放词背后都是各向异性:打印件强度看方向。
