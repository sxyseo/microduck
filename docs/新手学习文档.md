## 1. 你在做什么：一张项目地图

**Microduck** 是 Pollen Robotics 出品的一只双足机器鸭：25 厘米高、约 0.74–0.8 公斤重，身上 15 个舵机，用**强化学习**（不是人类逐帧编程）学会走路、起身、踢球。它的**软件完全开源**（Apache-2.0），机械和部分电路只公开了一部分 —— 所以社区在做的事情叫**复刻**：用官方公开的仿真模型、源码和逆向出来的资料，自己把一只造出来。你工作区里的所有目录，都是围绕这一件事。

### 先记住 6 个数字

| 数字 | 含义 |
|---:|---|
| **15** | 全机舵机数量（第 15 个驱动嘴巴，不参与走路） |
| **14** | 走路策略实际控制的关节数 |
| **61 → 14** | 神经网络：每次吃进 61 个数（姿态+关节状态），吐出 14 个数（每个关节往哪转） |
| **50 Hz** | 每 20 毫秒重复一次"读全部关节 → 算 → 下发"的循环 |
| **1 Mbps** | 舵机总线的通信速度 |
| **737 g** | 整机重量（其中头就占 189 g，接近 1/4 —— 这是它走路难训的根源） |

## 2. 十个必须先懂的概念（每个三分钟）

这十个词贯穿所有文档。更系统的版本见 [open-microduck 小白术语表](../open-microduck/docs/zh-CN/getting-started/glossary.md)。

**① 舵机（servo）**：自带减速齿轮和位置控制的电机总成。你告诉它"转到 90°"，它自己发力到位并保持。机器鸭的每个关节 = 一个舵机。

**② PWM 舵机 vs 总线舵机 —— 全项目最重要的一道分水岭。**
- **PWM 舵机**（如 SG90，约 9 克，玩具级）：一根信号线控制一只，靠脉冲宽度告诉它角度。**它不知道自己在哪**——被外力压偏了也不会告诉你。便宜、笨、没有反馈。
- **总线舵机**（如 Dynamixel XL330，18 克，本项目用它）：所有舵机像 USB 设备一样**串在一根线上**，各有编号（ID），主控点名问"2 号，你现在什么角度？"它答得上来，精度 12 位。
- 走路神经网络每 20ms 要读全部关节的真实位置和速度——**没有反馈的 PWM 舵机直接让 61 维输入里一大半变成假数据**。这就是"SG90 装不进这只鸭"的根本原因，不是嫌弃它便宜。

**③ 菊花链（daisy chain）**：总线舵机的接法——主板出来一根线进 1 号，1 号再出一线进 2 号，像串糖葫芦。一根总线挂 15 个。

**④ UART / I²C**：两种芯片间"说话的方式"（通信协议）。本项目里 **UART 管舵机总线**（1 Mbps，又快又简单），**I²C 管音频芯片和ToF 传感器**（400 kHz，两根线 SDA/SCL 挂多个设备）。记住：**UART 是"对讲机"，I²C 是"一条线上插多个电话分机"**。

**⑤ 半双工（half-duplex）**：一根线上既发又收，但同一时刻只能一个方向说。像对讲机"over"。舵机总线就是这样，需要一个"方向切换"小电路（一个缓冲芯片，原理图里的 U3）。

**⑥ IMU**：惯性测量单元，里面是陀螺仪+加速度计，输出"我现在是不是歪了、往哪边倒"。走路的神经网络**每一步都靠它感知身体姿态**。本项目的骚操作：IMU 板伪装成"200 号舵机"挂在总线上，姿态数据和关节数据一次全读回。

**⑦ 强化学习 / 策略 / ONNX**：不让人类写"先迈左脚再迈右脚"，而是让 AI 在物理仿真里摔几百万次，自己悟出平衡方法。悟出来的东西叫**策略（policy）**——本质就是一个数学函数：61 个数进，14 个数出。导出成 **ONNX** 文件（一种通用模型格式），机器人上的推理引擎直接加载它。

**⑧ Sim-to-real**：仿真里学会 → 真机上也能走。中间会丢真度，所以训练时要"域随机化"（故意加各种随机干扰，让策略皮实）。**仿真会走 ≠ 真机会走**，这句话所有文档反复强调。

**⑨ MJCF / MuJoCo**：MuJoCo 是物理仿真引擎（官方用来训练的"虚拟练跤场"）；MJCF 是它描述机器人身体的文件格式——里面精确记录了每个零件挂在谁身上、离多远、绕哪根轴转、多重。**复刻仓的装配图就是从这个文件反推出来的**。

**⑩ 公差与配合**：3D 打印的孔打出来会比图纸上小 0.1–0.3mm（材料收缩+挤料膨胀），所以画图时要**提前把孔放大**（补偿），或者打完用钻头修。装配能否顺利，80% 取决于这个细节。

## 3. 盘点你的家底

### 总览表

| 器材 | 身份 | 能干什么 | 不能干什么 |
|---|---|---|---|
| **Radxa Zero 3W** | ⭐ **官方同款主控**（官方就用这块板！） | 整个项目的"大脑"：刷 Armbian → 跑官方 Rust 运行时 → 加载 ONNX | 不能直接驱动 PWM 舵机 |
| **打印外壳件** | 机械结构件 | 收货实测（孔位验证）→ 试装 | 若打印时没做孔径补偿，孔可能偏紧 |
| **机器狗的舵机** | 待辨认（大概率 SG90 类 PWM 舵机） | **完美的入门台架**：学供电、接线、开环的宿命 | ❌ **不能装上鸭子**（无反馈、力矩 1/3、孔位不同） |
| **树莓派 Pi 2 Model B** | 地面调试台 | 跑 SG90 台架脚本；以后接 USB 适配器测总线舵机；无 WiFi，插网线 | 性能跑不动官方运行时的完整视觉栈（当台架够用） |
| **小智 ESP32 硬件** | AI 语音前端 | 第二阶段：语音"坐下/握手"→ 控制鸭子；或当 PWM 协处理器 | ❌ 现阶段与鸭子控制栈无关，**别让它分心** |

### 3.1 Radxa Zero 3W —— 你手里最好的一张牌

官方的"鸭子大脑"就是跑在这块板上的（RK3566 四核）。这意味着**软件零移植**：官方 Rust 运行时、9 个官方 ONNX 技能，硬件相同就能直接用，不用重训模型。

起步动作（第 2 周做，第 8 节有详细日程）：

1. 用 **Armbian imager** 刷 `Radxa Zero 3 / Armbian Minimal`，刷之前在界面里填好 WiFi 和账号密码（省掉串口线）；
2. `ssh` 进去，跑官方的 `./scripts/provision-board.sh` 一键装机（见 [官方安装文档](../docs/robot/install-dev.md)）;
3. 三个必踩的坑提前背下来（第 9 节）：串口被登录控制台占用、I²C 与 USB-C 供电协商抢引脚、NPU 默认关闭。

### 3.2 打印外壳件 —— 到手先当"验收员"

不要急着装。**先用 30 分钟当一次质检员**，这本身就是复刻项目的第一个正式实验（构建日志里叫 G1 验证）：

1. **M2 螺丝试穿**：拿 M2×6 螺丝逐件试穿腿部件的孔。能顺畅穿过 = 公差合格；穿不过的记下是哪件哪个孔（后面用 Ø2.5 钻头修，属正常操作）；
2. **轴承座**：Ø22mm 和 Ø15mm 轴承到手后试压入，"轻压不裂"= 合格；
3. **目检**：层纹方向、孔有没有变椭圆、明显缺料；
4. 全部记录进 [构建日志](../microduck-replica/构建日志.md)。

### 3.3 机器狗的舵机 —— 第一步：辨认它是谁

之前的指南记录你手头是 **SG90×6**。如果"机器狗的舵机"是另一批货，先花 5 分钟辨认（这决定它们能干什么）：

| 看什么 | PWM 舵机（玩具级） | 总线舵机（机器人级） |
|---|---|---|
| 型号印字 | SG90 / MG90S / MG996R / ES9051… | STS3215 / SCS / XL330 / HL-1910 / DS3218(部分)… |
| 重量手感 | SG90 约 9g，塑料齿轮 | 通常 40–60g，多有金属齿轮 |
| 引脚定义丝印 | `SIG + -` 或 `信号/红/棕` | `DATA/DATA+`、`TX RX` 或 DYNAMIXEL/FEETECH 字样 |
| 终极验证 | 接 PWM 信号才动 | 接串口后发"ping"命令有应答 |

**辨认结果的处理：**

- **是 SG90/MG90S 类（最可能）**：按第 4 节第 0 站，用 Pi 2 + [pi_sg90_bench.py](../microduck-replica/rl-series/scripts/pi_sg90_bench.py) 搭 PWM 台架，一晚上学四件大事（脉宽控制、供电预算、开环的宿命、动作序列）。这四课是后面所有接线调试的手感基础。
- **竟然是 STS3215 类总线舵机**：恭喜——它可以直接当第 1 站的"总线学习门票"（省下买第一只总线舵机的钱），但**仍然装不进这只鸭子**（尺寸大一圈、重 3 倍，强行换 = 换了一台机器人，详见 [执行器选型](../microduck-replica/docs/执行器选型.md)）。复刻构建日志里作者最终选了飞特 HL-1910 走"换舵机+重训"路线，代价是官方 9 个 ONNX 全部作废、要自己重训——那是后话，见 [换舵机重训全流程](../microduck-replica/docs/换舵机重训全流程.md)。

### 3.4 还缺什么（不用现在买齐，按第 4 节的门控节奏来）

- **15 只鸭子级舵机**（最大头，货期最长，第 3–4 周决策买什么）
- NP-F550 电池（注意是 **F550 不是 F970**，F970 装不进还超重 300g）
- IMX219 摄像头（就是树莓派 Camera v2）、VL53L5/8CX ToF、LSM6DSV16X IMU
- 两块电路板：RPI Robot HAT（**官方开源了全套制板文件，直接打样，不用画**）和 imu_to_dxl（复刻仓已画好，等你打样）
- USB 转舵机总线调试板（如 FE-URT-1，约 ¥45）——你的**第一张总线门票**

## 4. 学习总路线：四站

设计原则来自 [阶梯式采购与验证路线](../microduck-replica/docs/阶梯式采购与验证路线.md)：**每一笔大钱，都必须由上一站的验证结果来解锁**。新手期只花小钱、甚至不花钱。

```
第 0 站 手上和电脑上（¥0，本周）
   打印件实测(G1) + SG90 台架四课 + 仿真跑官方策略
        │  验证了：结构可用、你懂了开环的痛、策略长什么样
        ▼
第 1 站 电的最小闭环（≈¥250）
   USB调试板 + 1 只总线舵机 → ping、读写角度、50Hz 连读
        │  验证了：总线协议你玩得转（G2 门票）
        ▼
第 2 站 机械与自制板（≈¥150）
   腿部试装 + imu_to_dxl 打样贴片 → 总线 16 设备一次读回
        │  验证了：装得上、自制板有活数据（G3）
        ▼
第 3 站 大单与整机（≈¥2500–3500，货期长，提前下单）
   舵机×15 + 电池 + 传感器 → Radxa 起飞 → 整机 → 首走（G4）
```

| 站 | 花钱 | 你要学会的 | 验收标准 |
|---|---|---|---|
| 0 | ¥0 | PWM 台架四课；跑通官方仿真策略 | 6 只 SG90 做出序列动作；电脑上鸭子在仿真里走起来 |
| 1 | ≈¥250 | 总线协议：ID、波特率、读写寄存器 | 50Hz 连读 10 分钟零误包 |
| 2 | ≈¥150 | 装配手感；贴片焊接；IMU 数据 | 16 台设备一次 sync_read 全应答 |
| 3 | 大头 | 系统集成：供电、走线、标定、sim2real | 鸭子站立 + 遥控走两步（摔了也算数，记录它） |

**现在处于第 0 站。** 具体到天，看第 8 节。

## 5. 怎么看懂电路图

> 教材就是你仓库里这份：[imu_to_dxl-原理图.pdf](../microduck-replica/hardware/imu_to_dxl/imu_to_dxl-原理图.pdf)（全项目唯一要自己画的板，只有 5 个芯片，是完美的教学板）。配套 [接线表](../microduck-replica/hardware/imu_to_dxl/imu_to_dxl-接线表.md) 和 [设计包](../microduck-replica/docs/imu_to_dxl-设计包/)。

### 5.1 电路图到底在画什么

电路图（原理图，schematic）**不是电路板的照片**，而是"连接关系清单"的图形化。它只回答一个问题：**哪个引脚和哪个引脚电气上连在一起**。器件摆的位置、板子的形状，都不重要——那是 PCB 布局图的事。看图时把每根线理解为"导线"，而不是"画出的一条线"。

### 5.2 符号小字典（imu_to_dxl 图上全有，对照着认）

| 符号长什么样 | 名字 | 干什么 | 图上的位号 |
|---|---|---|---|
| 一堆平行短横线（像蜈蚣） | 电阻 | 限流、分压、"默认拉高/拉低" | R1–R7 |
| 两条平行线 | 电容 | 储电荷、滤掉电源毛刺（每个芯片电源脚旁必有一个 100nF，这是行规） | C1–C9 |
| 三角形+一竖线 | 二极管 | 电流单向阀 | D2 稳压管 |
| 三角形+闪电折线 | TVS 二极管 | "电压过高瞬间导通泄放"，保命用 | D1 |
| 三脚、像三明治 | 稳压芯片（LDO） | 把总线上的 6–8.4V 降成稳定的 3.3V 喂给芯片 | U4 HT7533 |
| 中间大方块、 many 引脚 | MCU（单片机） | 这块板的大脑，跑固件 | U1 STM32G031 |
| 方块+GND/Vdd+SDA/SCL | 传感器芯片 | IMU，走 I²C | U2 LSM6DSV16X |
| 方块+OE 脚 | 缓冲器/收发器 | 半双工方向切换的开关 | U3 |
| 一排小方块 | 排针/连接器 | 接线、烧录、总线进出 | J1–J5 |
| 中间画" Fuse "或波浪矩形 | 自恢复保险丝 | 电流过大自动断，冷却后恢复 | F1 |

### 5.3 读图五步法（任何原理图通用）

1. **找电源入口**：电从哪进？（这里是 J1/J2/J4/J5 四个座的 pin2，标着 `VDD_BUS`，6.0–8.4V）
2. **找地（GND）**：所有器件的 GND 汇成一张网。**没有共同的地，一切信号都没有参照**——接线事故 80% 出在地线上。
3. **找主芯片**：最大那块（U1 STM32）。看它的电源脚（VDD→+3V3、VSS→GND）先接对没有。
4. **顺着网络标号走**：图上不会把每根线都画出来，相同名字（如 `+3V3`、`SWDIO`）就是连在一起的。这是原理图的"超链接"。
5. **看连接器**：J1–J5 是板子与外界的全部接口，弄清每个 pin 是什么，接线表就能自己读了。

### 5.4 实战：把 imu_to_dxl 图读成一句人话

打开 PDF，按信号流走一遍：

```
舵机总线 6–8.4V ──► F1 保险丝 ──► D1 TVS 钳压 ──┬──► 直接喂给总线座（原压直通，舵机要这个电压）
                                               └──► U4 稳压成 3.3V ──► 喂 U1(MCU) 和 U2(IMU)
U1 STM32 (大脑) ──UART──► U3 半双工缓冲 ──► 总线DATA线（会说话也能听）
U2 IMU ──I²C(SDA/SCL)──► U1（IMU 汇报姿态）
J3 排针 ──► SWD 烧录口（给 U1 灌固件用）
```

一句话总结这块板：**"把 IMU 的姿态，翻译成舵机总线上 200 号设备的答复"**。再对照接线表看 `+3V3` 网络：U4 输出 → U1.4 → U2.5/U2.8 → U3.8 → 每个芯片旁边挂一个 100nF（C1–C4）——你看，"每个芯片电源脚旁必有小电容"这条行规，在你自己的图里应验了。

### 5.5 新手电工四件套（比看图更先学会）

1. **万用表两件事**：通断档（蜂鸣响 = 两点直通，用来验证接线）和直流电压档（量电池、量 3.3V/5V）。
2. **共地**：两个电源给两个设备供电时，地线必须连在一起，否则信号没有参照。鸭子也一样：舵机侧 6V 和主控侧 5V **必须共地**。
3. **先量后上电**：任何接线完成，先不通电量一次"电源对地有没有短路"（通断档响 = 有短路，停）。
4. **绝缘**：焊点套热缩管或点热熔胶。舵机总线上 15 个设备共线，一处短路全线瘫痪。

### 5.6 工具

- **嘉立创 EDA**（免费，国产）：能直接打开仓库里的 `imu_to_dxl.eprj2` 工程看图改图；打样也是它一键下单；
- **Dynamixel Wizard 2.0**（ROBOTIS 官方，免费）：配 USB 调试板后，图形界面扫总线上的舵机、改 ID、读角度——**你第一个"电路活了"的成就感来自这个软件**。

## 6. 结构怎么看、怎么设计

> 教材：[microduck-replica-cad/](../microduck-replica-cad/README.md)（56 个 SolidWorks 零件 + [21 页装配安装说明书 PDF](../microduck-replica-cad/安装说明书/microduck装配安装说明书.pdf) + 23 张组件图/爆炸图）、[打印工艺调整表](../microduck-replica/docs/打印工艺调整表.md)、[紧固件反推](../microduck-replica/docs/紧固件反推.md)。

### 6.1 好消息：你不需要"从零设计"

复刻项目的结构已经被反推/重建过一遍：47 个官方仿真 STL → 装配关系精确到 0.1mm → 爆炸图、BOM、SolidWorks 装配体全套现成。你的路径是：**先学会"装配"（读懂它为什么这么设计），再学"改"（加个走线槽、换个卡扣），最后才是"设计"**。对新手，前两步已经覆盖 90% 的需求。

### 6.2 先读懂这只鸭子的骨架（10 分钟）

看 [装配爆炸图](../microduck-replica/assembly-drawings/) 或组件图目录，对着下面这棵树：

```
躯干主体 199g（装配基准件，一切从它开始）
├─ 左腿: 髋yaw(23g) → 髋roll(6g) → 大腿(48g) → 小腿(22g) → 踝+脚(30g)
├─ 右腿: 同上（左右镜像）
└─ 颈根(37g) → 颈俯仰(6g) → 头yaw/roll机构(49g) → 头部总成+喙(189g)
```

三个观察，理解"设计意图"：

- **每条腿 5 个关节**（yaw 转向 / roll 侧摆 / pitch 前后摆 / 膝 / 踝）——双腿 10 个 + 头颈 4 个 = 14 个受控，第 15 个管嘴；
- **头几乎和躯干一样重**（189g vs 199g）。头是甩来甩去的大摆锤，重心极高——这就是走路策略难训的原因，也是"别自己乱加重物在头上"的原因；
- **全部 M2 螺丝系统**：过孔 Ø2.2（螺丝穿过）×111、沉头孔 Ø4.4（螺丝头埋进去）×48、攻丝底孔 Ø1.6（拧自攻螺丝）×27。三种孔三种用途，装配时认清楚。

### 6.3 结构设计入门十词

| 词 | 一句话解释 |
|---|---|
| 自由度（DOF） | 一个关节能独立动的方向数。髋 pitch 只能前后摆 = 1 自由度 |
| 运动链 | 关节连成的一条链：躯干→髋→膝→踝。链末端（脚）的位置由链上每个关节决定 |
| 基准件 | 装配从哪个零件开始。躯干是基准，先把它固定好 |
| 过孔 | 让螺丝穿过去的通孔，Ø2.2（M2 螺丝杆 2.0 + 余量） |
| 沉头孔 | 让平头螺丝头**埋进表面**的台阶孔，Ø4.4 |
| 攻丝底孔 | 拧自攻螺丝的孔，Ø1.6——塑料里拧 M2 自攻，靠材料自身被挤出螺纹 |
| 轴承座轻压入 | 轴承装进孔里，公差刚好到"用手轻压进去、不晃不裂" |
| 热熔螺母 | 用烙铁把铜螺母烫进塑料孔，得到可反复拆装金属螺纹 |
| 公差补偿 | 打印孔会缩 0.1–0.3mm，画图时提前放大 +0.15~0.25 |
| 走线空间 | 结构腔体里要给舵机线和电路板留通道——**复刻件最大的坑就是没走线空间** |

### 6.4 3D 打印工程第一课：测试片先行

别直接打印整套。先打一张 [打印工艺调整表](../microduck-replica/docs/打印工艺调整表.md) 第二节的 **60×40×4mm 测试片**（上面有孔径三档阶梯：M2 过孔/攻丝/沉头 + 轴承孔 Ø21.9–22.1），实测你的打印机+耗材的收缩量，把补偿值记下来，再批量打印。耗材预算：全机约 300g PLA，一公斤卷足够。

### 6.5 想动手改结构：软件路线

1. **看**：先用 PDF 阅读器翻完 21 页装配说明书（不用装任何软件）；
2. **转**：装 **FreeCAD**（完全免费）打开 `cad/` 下的 STL 装配体，学会旋转/剖切/测量三个操作；
3. **改**：给自己定一个 30 分钟小任务，比如"给躯干内腔壁加一条 3mm 走线槽"——用草图+拉伸两个功能就能完成；
4. （可选）**学**：Fusion 360 个人版免费，B 站搜"Fusion 360 入门"，跟完一个杯子/盒子教程就够用。

### 6.6 装配顺序经验

照 21 页说明书走，大原则：**躯干 → 双腿 → 头颈**；每装完一个组件手动转一下关节（应顺滑无卡滞再装下一个）；M2 自攻螺丝不要拧到底硬怼（塑料滑丝不可逆）；舵机装上前先在调试板上设好 ID（装完再改 = 全部拆开重来）。

## 9. 必踩的坑

1. **Armbian 的登录控制台占着 ttyS2**（舵机总线用的串口）。`sudo systemctl mask serial-getty@ttyS2` 屏蔽掉，否则总线发疯。
2. **i2c3 与 USB-C 供电协商抢引脚**。用排针 3/5 脚的硬件 I²C 的代价是失去 PD 快充协商（普通 5V 充电不受影响）。
3. **NPU 出厂默认关闭**。要跑视觉模型需刷 overlay 并重启。
4. **舵机出厂 return_delay=500µs**，16 台设备一 tick 就吃掉 8ms——必须全部写 0，否则 50Hz 循环装不下。
5. **XL330 是超压运行的**（舵机直接吃电池 6.6–8.2V，标称只有 5–7.4V）。这是官方设计特性，不是接错；但意味着你的供电方案要能扛。
6. **SG90/机器狗舵机装不进鸭子**。不是歧视，是物理：没有位置反馈 + 力矩 1/3 + 孔位不同。它们的岗位是台架教具。
7. **打印孔缩 0.1–0.3mm**。测试片先行，补偿值回填后再批量。
8. **电池是 NP-F550，不是 F970**。买错装不进，还重 300g。
9. **两套舵机 ID 表不要混用**：平价教程路线（Microduck-build-tutorial）用 ID 1–15；官方/复刻路线用 10–14（右腿）、20–24（左腿）、30–34（头颈嘴）、200（IMU）。照哪条路线就用哪张表，混了全乱。
10. **永远不要直接拔电**。先 `sudo shutdown -h now`，等 15 秒再关电源开关，SD 卡和文件系统会感谢你。
11. **总线上偶发丢包（约 0.27%）是正常的**，官方运行时自带容错（连丢 3 tick 才算故障）。别看到一个 CRC 错误就拆机。
12. **第一次真机运行必须手扶**，且不要在桌边——摔倒不是失败，是数据。

## 10. 安全守则

- 上电前：万用表确认电源正负极、确认无短路（通断档）；
- 电池：不过放（NP-F550 单芯 <3.0V 就停）、不短路存放、充电时人不离开；
- 焊接：焊点套热缩管；烙铁离开就放支架；通风；
- 舵机：堵转（被卡住还猛发力）几秒内就能烧齿轮/芯片，听到"嗡嗡"异响立刻断电；
- 真机测试：低重心、软垫、手扶、远离桌沿；
- 关机流程：软件关机 → 等 15 秒 → 断电源开关。
