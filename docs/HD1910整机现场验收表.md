# HD-1910-C001 整机现场验收表

这是一张现场操作单，配合 [HD-1910 全链路落地手册](HD1910全链路落地手册.md) 使用。
每完成一项就填写"结果"和"证据"，不要凭记忆跳过步骤。
`通过`只表示这一项通过，**不表示机器人可以行走**；`motion_enabled` 在 H7 全部成立之前保持 `false`。

关节名称与官方 ID 的权威对照见
[URT2-HD1910 接线组装与测试指南](URT2-HD1910接线组装与测试指南.md) §7 和 `microduck-servo-guide`。
本表只记录**你这台机器实测到的值**，不复制任何样例数值。

## 7. H6 — IMU 安装方向核对与 verify-imu

前置：模块已刚性固定在躯干，位置与 H1–H5 期间一致。⚠️ **不得凭模块丝印推轴向**，

### 8.2 反向：IMU → 关节残差（用 IMU 当量具）

| 关节 | 已知角度 ° | IMU 反解零位残差 ° | 残差是否随躯干初始姿态变化 | 判定 |
|---|---|---|---|---|
| | | | ☐ 不变 ☐ 变 | ☐ 舵机零位错 → 回 H5 ☐ mount 错 → 回 H6 |

分不清就再加一个初始姿态（整机侧倾 15°）重跑，不要靠猜。
