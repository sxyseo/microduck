## 1. 这只鸭子多少钱:先看真账

[项目主页](https://duck.whatled.com)晒的实付账单:

| 已实付三笔 | 金额 |
|---|---:|
| 舵机 飞特 HL-1910-C001 ×15 | ¥1,500 |
| 主控 Radxa ZERO 3W | ¥299 |
| 外壳打印(代打,PLA 41 件) | ¥99 |
| **合计已付** | **¥1,898** |

总预估降到 **≈¥2,460**(原估 ¥3,500–4,500,舵机实价拉低下调)——对照官方整机 $399 ≈ ¥2,900,照这个节奏,自制有机会比官方还便宜。注意:这个数**不含已有的 3D 打印机与工具**。一眼可见的规律:**舵机占大头**。所以最大的省钱决策发生在舵机上:主控缺货期以 ¥100/只 购入飞特 HL-1910,替代 XL330 方案(报价 ≈¥2580+),**省约 ¥1100**——换对舵机省的钱,比砍任何小件都多。

## 2. 下单顺序:长货期先买,拿不准的等一等

项目记录的真实顺序,值得照抄:

1. **大头先落地**:舵机 ¥1500 先付——它最贵、货期最不确定;主控缺货,到货窗口一开就付 ¥299;
2. **测试片先行,不急着批量打印**:外壳 41 件是否开打,由测试片的孔径补偿决定(第 09 课)——先打一张 60×40×4mm 的片子;
3. **拿不准的等一等**:连接线要等舵机到货、确认出线插头(5264 还是 XH/PH)再下单,不然买回来插不上;
4. 剩余清单分三批:①本周 ≈¥180(调试板/线材/轴承/螺丝/热熔螺母/TPU 件)→ ②电子 ≈¥280(电池+扣板/转接板/摄像头/ToF)→ ③自制板 ≈¥100(第 11 课那块板的打样+元件)。

**所以呢**:下单顺序本身就是风险管理——把钱花在卡脖子件上,把等待留给便宜件。

## 3. 采购单要规格导向,不是价格导向

真实教训(构建日志 2026-09-08):此前的采购单以"链接 + 快照价"为主,电商价格天天漂移对不上,更要命的是部分条目没写验收规格,看单的人"不知道买哪个"——用户反馈原话:**"价格不对、规格没写"**。

改版后的正确格式,每一条 = **搜索词 + 验收规格 + 数量 + 约价区间**,链接降级为参考:

```text
示例条目
舵机连接线:10/15/20cm 各 5 条,30cm+ 不要(按鸭子几何定量)
轴承:16×22×4 薄壁深沟球,带防尘盖(注意不是常见的 608 规格,防买成推力轴承/法兰)
电池:2S 锂电,外形尺寸 ≤___mm(排除 F970 相机电池)
电源扣板:输出须 7.4V 直出(防买成只出 5V 的)
转接板:确认支持 1Mbps
```

一句话总结这条教训:**采购单的生命是规格,不是链接。** 有规格,任何店铺都能比对;只有链接,店铺一改价你就瞎了。

## 4. 实付记账:估价和实付要分两栏

项目从 2026-09-06 起养成实付记账习惯:已付三笔单独列,其余仍标"估价",互不冒充。好处:总账真实(¥1,898 是花了的,≈¥2,460 是估的,一目了然);退款换货有凭证;复盘能看出哪些东西比估价贵了(如 Radxa ¥299,略高于 BOM 估价)。你也照做:一张表四列——日期、条目、实付金额、订单号或截图。

## 5. 哪些东西可以不买/后买

- **3D 打印机**:不买。代打 ¥99 解决 41 件——"没打印机就代打,别为一只鸭子专门买 ¥2,500 的打印机";
- **TPU 软件两件**:后买。被 PLA 代打店拒收后单独补打,约 ¥30–50,不在关键路径(第 3 周才装头部);
- **手头已有的器材先榨干**:SG90×6 + Pi 2 组成 ¥0 入门台架(第 10 课),ESP32/扩展板封存备用;
- **GPU**:阶段 D 之前不存在的开销,本机 CPU 已能跑冒烟实验(构建日志:单组 4 分钟)。
