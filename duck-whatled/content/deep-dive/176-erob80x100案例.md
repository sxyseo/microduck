# 解读 176 · erob80_100 案例研究

> **解读对象**:`bam/bam/params/erob80_100/`(m1.json–m6.json 六档,m6.json 共 15 个字段)
> **需要的前置**:[解读 175](175-erob80x50案例.md)(erob80_50 案例)· [解读 163](163-齿轮与减速比.md)(减速比)

## 1. 型号是谁

eRob80:100——[解读 175](175-erob80x50案例.md) 那颗 eRob80 的减速比翻倍版:同一个
`ErobActuator` 电流控制类(48 V / 12 A、amps 控制律、etherban protobuf 协议),注册表里
唯一差别是构造参数 `damping=2.0`(50 版是 1.0)——同一台架电流律,阻尼项加倍。
`:100` 指减速比(命名惯例,厂商背景:参数库外待验证)。它是全库 kt、armature、
friction_viscous 三项的冠军,也是**唯一一份缺 `R` 的 json**。

## 2. m6.json 逐字段 + 与 xl330 基准对比

15 个字段——比 erob80_50 还少一个 `R`(缺失=加载时回落类初始值 2.0 Ω;[解读 80](80-BAM参数逐字段.md)
的猜测是辨识时被 `fit --set` 锁参冻结,待验证):

| 字段 | erob80_100 | erob80_50 | xl330 |
|---|---|---|---|
| `kt` | **9.396** | 4.897 | 0.346 |
| `R` | **缺失**(回落 2.0) | 1.07 | 2.50 |
| `armature` | **1.135** | 0.362 | 0.00157 |
| `friction_base` | 4.8e-04 | 3.26 | 0.0119 |
| `friction_stribeck` | **5.23** | 0.320 | 0.00085 |
| `load_friction_motor/external` | 0.0489 / 7.6e-08 | 0.0357 / 8.4e-04 | 0.228 / 0.107 |
| `load_friction_*_stribeck` | 8.8e-06 / 0.0512 | 0.00377 / 0.0414 | 1.5e-08 / 0.142 |
| `load_friction_*_quad` | 0.00270 / 0.00256 | 0.00187 / 0.00160 | 0.00527 / 0.00299 |
| `dtheta_stribeck` | 2.03 | 2.83 | 0.261 |
| `alpha` | 3.00 | 1.79 | 8.53 |
| `friction_viscous` | **9.709** | 1.403 | 0.00579 |

孪生对照是这篇的正戏,**减速比翻倍的物理后果逐项显形**:
- kt 4.897→9.396,×1.92 ≈ 2:输出端力矩常数 ∝ 减速比——4.897×2=9.79,与辨识值 9.396
  差 4%,教科书级的自洽([解读 163](163-齿轮与减速比.md):扭矩放大、转速减半)。
- armature ×3.1:若按反射惯量 ∝ 减速比² 的口径,0.362×4≈1.45,与 1.135 同量级(推断口径,待验证)。
- 摩擦预算换了个放法:50 版是"库仑底 3.26 扛大头",100 版变成"Stribeck 5.23 扛大头、
  库仑底归零"——同为 M6 档,形状完全不同。
- viscous ×6.9:9.709 N·m/(rad/s),常规档上限 1.0 的近 10 倍,靠 ErobActuator 放宽到 30 才装下。
- 力矩天花板:kt×12 A ≈ **112.8 N·m**;而速度被减速比压半——力矩-速度守恒的代价。
- 存疑点:dtheta_stribeck=2.03 超 1.0 上限(同 175,旧版范围拟合推断);R 缺失回落 2.0,
  意味着任何用到 R 的计算(如电压边界 (kt/R)×48≈226 N·m)都在用"没辨识过的默认值"。

## 3. 如果用它换掉 xl330:五落点具体值

与 [解读 175](175-erob80x50案例.md) 同构,四道门一门不过(48 V/12 A 供电、外形、
etherban 私有协议、质量量级),只列差异:① `motor_name="erob80_100"`;② forcerange 按
100 N·m 量级、摩擦值指向本 json;⑤ 质量/惯量按 100 版重算。它的真正用途同 175:
**方法论边界测试 + 高扭矩参照系**。给读者的实用启示反而是负面的——连 R 都没有的 json
照样能进库被加载,说明 `load_model` 对字段缺失是"静默回落默认值":用别人的 json 前,
先数一遍字段数,再对一遍类里的初始值,否则你在用两个没辨识过的数做仿真。

## 你带走的收获

- kt ≈ 2×、减速比 ×2:输出端力矩常数与减速比成正比,辨识值 9.396 对公式值 9.79 差 4%,
  json 也能验算。
- 同一执行器族换减速比,摩擦预算会"换形状"(库仑底扛 → Stribeck 扛),而不是简单缩放。
- 缺失字段静默回落类初始值(R=2.0 从未被辨识):用 json 前先数字段,警惕"没测过的默认值"。
- viscous 9.709 vs xl330 的 0.00579(×1677):全库最悬殊的一对数,跨量级选型没有"微调"可言。
