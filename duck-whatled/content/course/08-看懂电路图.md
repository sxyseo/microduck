## 1. 电路图在画什么:地图,不是照片

原理图(schematic,电路图)**不是电路板的照片**,而是"连接关系清单"的图形化。它只回答一个问题:**哪个引脚和哪个引脚电气上连在一起**。器件摆哪、板子长什么样,都不重要——那是 PCB 布局图的事。看图时,把每根线理解成"导线",而不是"画出的一条线"。

教材就用你仓库里这份:`microduck-replica/hardware/imu_to_dxl/imu_to_dxl-原理图.pdf`——只有 5 个芯片,是完美的教学板。

## 2. 符号小字典(imu_to_dxl 图上全有)

| 符号长什么样 | 名字 | 一句话解释 |
|---|---|---|
| 一堆平行短横线(像蜈蚣) | 电阻 R1–R7 | 限流、分压、"默认拉高/拉低" |
| 两条平行线 | 电容 C1–C9 | 滤掉电源毛刺。**每个芯片电源脚旁必有一个 100nF,这是行规** |
| 三角形+一竖线 | 二极管 D | 电流单向阀 |
| 三角形+闪电折线 | TVS 二极管 D1 | 电压过高瞬间导通泄放,保命用 |
| 三脚、像三明治 | 稳压芯片(LDO)U4 | 把总线 6–8.4V 降成稳定的 3.3V 喂给芯片 |
| 中间大方块、许多引脚 | MCU(单片机)U1 | 这块板的大脑,STM32G031 |
| 方块+SDA/SCL | 传感器 U2 | IMU,走 I²C(一种两线的芯片间通话协议) |
| 一排小方块 | 排针/连接器 J1–J5 | 板子与外界的全部接口 |

## 3. 读图五步法(任何原理图通用)

1. **找电源入口**:电从哪进?这张图是 J1/J2/J4/J5 四个座的 pin 2,标着 `VDD_BUS`,6.0–8.4V。
2. **找地(GND)**:所有器件的 GND 汇成一张网。没有共同的地,一切信号都没有参照——接线事故 80% 出在地线上。
3. **找主芯片**:最大那块(U1)。先确认它的电源脚接对了:VDD→+3V3,VSS→GND。
4. **顺着网络标号走**:图上不会把每根线都画满,相同名字(如 `+3V3`、`SWDIO`)就是连在一起的。这是原理图的"超链接"。
5. **看连接器**:J1–J5 是板子通向外界的全部窗口,弄清每个 pin 是什么,接线表就能自己读了。

**所以呢**:以后拿到任何原理图,不管多吓人,先按这五步走一遍,它就从"天书"变成"填空题"。

## 4. 实战:把 imu_to_dxl 读成一句人话

按信号流走一遍:

```text
舵机总线 6–8.4V → F1 保险丝 → D1 TVS 钳压 ─┬→ 直通总线座(舵机要原压)
                                            └→ U4 稳压成 3.3V → 喂 U1(MCU)和 U2(IMU)
U1(大脑) ──UART──→ U3 半双工缓冲 ──→ 总线 DATA 线
U2(IMU) ──I²C──→ U1(汇报姿态);J3 = SWD 烧录口
```

一句话总结这块板:**"把 IMU 的姿态,翻译成舵机总线上 200 号设备的答复"**。再对照接线表看 `+3V3` 网络:U4 输出 → U1 → U2 → U3,每个芯片旁边挂一个 100nF——第 2 节那条行规,在你自己的图里应验了。

## 5. 新手电工四件套(比看图更先学会)

1. **万用表两件事**:通断档(蜂鸣响=两点直通,验证接线)和直流电压档(量电池、量 3.3V/5V)。
2. **共地**:两个电源分别供电时,地线必须连在一起,否则信号没有参照。
3. **先量后上电**:接线完成后,先不通电量一次"电源对地有没有短路"——响就是短路,停。
4. **绝缘**:焊点套热缩管。总线上 15 个设备共线,一处短路全线瘫痪。

工具两样,都免费:**嘉立创 EDA**(打开仓库里的 `imu_to_dxl.eprj2` 看图改图,打样一键下单)和 **Dynamixel Wizard 2.0**(图形界面扫总线,你第一个"电路活了"的成就感来自它)。安全一句:别看只是几伏低压,锂电池脾气不小——**不短路存放、充电人不离开、不过放**。
