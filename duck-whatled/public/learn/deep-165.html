解读 165 · 质心与配重:头的 189g

解读对象:概念课 · 以 microduck-replica/README.md(装配结构/整机数据)为教材
需要的前置:解读 38;知道"重心"=全部质量合成的等效点。

一棵会加法的质量树

README 的装配结构是一棵带质量的树:

躯干主体 199g
├─ 左腿:髋 yaw→roll 23g → 髋 roll 6g → 大腿 48g → 小腿 22g → 踝+脚 30g
├─ 颈头:颈根 37g → 颈俯仰 6g → 头 yaw/roll 机构 49g → 头部总成+喙 189g
└─ 右腿(与左腿镜像,同质量)

整机 737.2g   外形 144 × 141 × 264 mm(25cm 高)

左右腿各 129g,颈头链 281g,躯干 199g,加总 738g——与 737.2g 在取整误差内对上。一条腿从头到脚 129g,脖子上那串 281g:这就是这只鸭子的质量地理,也是"质心高"三个字的量化版。

为什么头重是走路大敌

README 的结论只有一句:"躯干和头几乎一样重(199g vs 189g)——头部占整机四分之一,重心很高,这解释了为什么它的行走策略难训。"拆开来是三条机制(回扣解读 38):支撑面在脚底,重心越高,同样侧倾角下重力把鸭子"扶回来"的力矩臂越短,越易摔;头是挂在三个串联关节末端的摆锤,甩头的角动量直接灌进躯干姿态;落地冲击沿颈链上传,头里的主控、HAT、摄像头跟着震。

配重意识从这里长出来:往头上加 10g 装饰,等于同时给整机质心、整机惯量、三个颈关节的负载加码。"别往头上乱加东西"不是审美建议,是 189/737.2 这笔账。

电池:一份真实的"配重"

全机最重的单件不在线束里,在背面:README 与《硬件方案逆向》都写明"电池外挂在机身后下方"。逆向文档的 MJCF 反推数据里,这块 39×21×71mm 的电池 X 范围 −55.3…−16.7mm——按文档的坐标约定,负 X 是壳体背面;而躯干刚体的质心写在 X = −22.6mm,同样偏背面。头颈在正面最高处,电池贴背面中线压低——从配重的眼光看这是一次对冲(设计意图文档未明说,此处按数据判读,存推断)。

训练侧还留了一手:走路配置的域随机化把躯干质心随机 ±3mm、课程逐步扩到 ±15mm,头部组件 ±3mm(docs/course/13-参数地图.md 引训练指南)——策略必须学会容忍质心漂移,因为真机的 737.2g 永远不会和仿真一模一样。

你带走的收获

  • 质量树会加法:129g 的腿对 281g 的颈头链,一眼看出这只鸭子"头重"。
  • 重心高的三条代价:恢复力矩短、摆锤扰动、冲击传导(解读 38)。
  • 配重的真实案例是电池:机身后下方、贴中线,对冲头的前上质量。
  • 质心随机化 ±3 到 ±15mm:策略级的配重保险,容忍实物与仿真的差距。
  • 任何"往头上加点什么"的念头,先过 189g ÷ 737.2g ≈ 四分之一整机这笔账。
