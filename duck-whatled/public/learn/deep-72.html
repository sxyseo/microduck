解读 72 · 一次性投入与下一次换舵机:降本路线+总验收

解读对象:docs/HL-2915路线全流程教程.md(380 行)§9–§11(降本、速查、总验收)
需要的前置:解读 58(为什么官方 ONNX 作废)、解读 52(选型对比方法)

这是专辑的最后一篇。§9 回答贯穿全系列的问题:A–G 走完,哪些是沉没成本,哪些变成了资产?§10–§11 把踩过的坑和全部验收收拢成两张可复用的表。

1. 什么是一次性的

§9.1 点名:转接板、教程本身、hl2915_bench.py、Feetech2915Io、辨识方法、部署流水线全部复用。换一只更便宜的舵机,边际成本只剩三件事:

要动的 工作量
电压窗与保护寄存器(14/15/28 号) 一条写指令
寄存器差异(以那只舵机的内存表为准,如经典 STS 系列) 改两个常量 + 重跑课 1–5
辨识五参数重测 + 重训 阶段 A 的表 + 阶段 F 一轮

这就是"换参数,不是重做"的准确含义:探索性的工作(协议猜谜、IMU 朝向、供电架构、Io 接缝)只付一次,之后付的都是确定性的执行——包括"以那只舵机的内存表为准"这条限定:经典 STS 系列协议同族,目标位置地址却不同。

2. 候选、规则与成本锚点

教程 §9.2 的三行候选表:HL-2915-C001(9–14V,27.8g,本教程的开发单元);HD-1910-C001(4–8.4V,21g,2S 母线友好;⚠️ 脚序与 HL 相反:1=Signal / 2=Vcc / 3=GND,HL 是 1=GND/2=Vcc/3=Signal,hl2915_bench.py 头注释的线序);STS3215 系列通用货(4.8–7.4V,~21g,lerobot 同款)。

选型规则:整机验收前不要囤货;先用 2 只开发舵机把阶段 F 走通,G 阶段按"单只价格 × 15 + 辨识偏差风险"决定量产型号;同一批货全部同型号同固件批次——"混批是最隐蔽的坑"。成本锚点(§9.3):官方整机 $399,HAT 打样几百元起,对照转接板 ¥22 + UBEC。

3. 故障排查速查表:把症状映射到层

§10 的九行速查表,每行"症状→原因→动作":总线(PING 无应答→量母线电压、核线序;全 0xFF→查共地);舵机配置(12V 一上就假死→14/15 号电压窗出厂值低于 12V 触发过压保护);部署(policy load 被拒→inspect_onnx.py 验 61/14);整机(吊装某关节狂抖→回阶段 A 标定记录核对方向位)。它是 §0"跳步的代价"的逆索引:出问题先问该查哪一层。

4. 总验收清单与结语

§11 的清单可直接复制打勾(教程原文):

阶段 A:[ ] 课1–4 两只各自 PASS   [ ] 课5 SYNC 闭环   [ ] 辨识四项数据入表   [ ] ID 分配贴标
阶段 B:[ ] 零漂<0.05rad/s  [ ] 翻转变号  [ ] 方向对  [ ] 四元数连续  [ ] 50Hz×10min 不 stale
阶段 C:[ ] v4l2 出图  [ ] 720p30 流  [ ] 方向正确  [ ] duck-detect 框对
阶段 D:[ ] 3S 母线 12.3–12.6V  [ ] 压降<0.5V  [ ] 急停可靠  [ ] UBEC 5V 稳  [ ] 全部共地
阶段 E:[ ] cargo test 绿  [ ] 50Hz 零丢读  [ ] 扭矩开关正常  [ ] 拔线报 ShortRead
阶段 F:[ ] 冒烟无 NaN  [ ] 训练三信号  [ ] export.py 导出  [ ] inspect 61/14  [ ] 回放能走
阶段 G:[ ] health 绿  [ ] L5 吊装  [ ] L6 软垫  [ ] L7 平地  [ ] 日志留档

全专辑收束于此。第一次走 A–G,按 §0 的预估约 5–8 周;下一次换舵机,固定动作收敛为"改常量、重测五参数、重训一轮"。换舵机成本从整月压到几天的方法论版本:没有一步需要重新发明。教程结语值得抄在台架边:"真正降本的不是便宜的舵机,是少走一遍弯路。"

你带走的收获

  • 沉淀资产的标准:下次换件还能原样用的才是资产——脚本、Io 层、辨识方法、部署流水线。
  • 选型先定流程再定型号:2 只先走通重训,15 只的订单等辨识偏差风险算清再下;批次一致性是隐性参数。
  • 故障排查表按"层"而非按"器件"组织,与教程 §0 的顺序约束互为正反面。
  • 验收清单的最小粒度是"可打勾的数字",不是"感觉对了"。
