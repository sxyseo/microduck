第 09 课 · 3D 打印第一课:测试片先行

这一课解决什么问题:仿真 STL 不是可打印工程件。这一课教你用一张 60×40×4mm 的测试片,先摸清自己打印机(或代打店)的真实精度,再决定全机 41 件要不要开打。

前置:无硬性前置,可与第 08 课并行。练习需要能碰到一台 3D 打印机——自己的或代打店都行。

1. 核心判断:仿真 STL 不是可打印工程件

官方公开的 47 个 STL 是给仿真用的:仿真只保证外形与惯量(第 01 课你开的就是它),不保证配合公差、螺纹、埋件座和走线空间。microduck-replica/构建日志.md 开头反复强调这句话,整个打印阶段就是在验证它到底对不对。

翻译成人话:仿真里零件永远严丝合缝,真打印出来孔可能小 0.1–0.3mm(孔会缩),螺丝拧不进、轴承装不上。所以别直接打印整套。

2. 先认识 5 个结构词

全机是 M2 螺丝系统(过孔 ×111、沉头孔 ×48、攻丝底孔 ×27),这三个词必须分清:

词 一句话解释
过孔 螺丝穿过去的孔,Ø2.2(比螺丝杆 2.0 略大)
沉头孔 让螺丝头埋进表面的台阶孔,Ø4.4
攻丝底孔 拧自攻螺丝的孔,Ø1.6——靠塑料被挤出螺纹
公差补偿 打印孔会缩,画图时提前放大(参考值 +0.15~0.25mm)
轴承座轻压入 轴承用手轻压就能进、不晃不裂——配合松紧刚刚好

3. 测试片测什么:一张片子,五组阶梯

microduck-replica/docs/打印工艺调整表.md 第二节给了现成的测试片设计,30 分钟出结论:

过孔阶梯  Ø2.2 / 2.3 / 2.4 / 2.5   ← 哪档螺丝"刚好能过"?
攻丝阶梯  Ø1.6 / 1.65 / 1.7 / 1.75 ← 哪档自攻"拧得进且不裂"?
沉头一对  Ø4.4 + Ø2.2              ← 螺丝头能沉平吗?
轴承孔    Ø21.9 / 22.0 / 22.1      ← 22×16×4 轴承的压入配合三档
小轴承孔  Ø14.9 / 15.0 / 15.1      ← 15×10×3 轴承

判定标准:螺丝以手指力量能顺畅通过 = 合格过孔;自攻拧入 3 圈以上不裂不旷 = 合格底孔。

4. 回填公差补偿:最值钱的一行数据

测完不是就完了——把每一档的实测结果回填进你的切片参数(孔径补偿),再记进 构建日志.md 的「尺寸与配合验证」表。这张表决定全部 41 件是否直接开打,是整个复刻里对后来者最值钱的一行数据。

一条纪律(工艺调整表原话):全部件用同一台机器、同一材料、同一层高打——否则补偿值跨机器就失效了。

5. 代打 vs 自打:¥99 的真实经验

没有打印机怎么办?项目自己的答案是:代打。构建日志 2026-09-06 记录:¥99 按重计价的代打店,PLA 41 件搞定(全机约 300g PLA,一公斤卷都用不完)。但有两个真实教训:

  • TPU 被拒收。软下巴 + 软嘴两件(共 26g)是 TPU(软性耗材),该店只做 PLA。评估结论:只影响叼取技能和连杆弹性,不影响走路/装配/发声,单独找 TPU 渠道补打即可(约 ¥30–50,不在关键路径)。注意一句忠告:别让店家降填充冒充软料。
  • 测试片先行同样适用于代打:先让店家打测试片,定了补偿值再批量下单,别让 41 件一次全废。

6. 动手练习(30 分钟 + 打印时间)

  1. 从打印工艺调整表拿测试片 STL,打一张(自打)或让代打店打一张;
  2. 逐档试装:M2 螺丝穿过哪一档?自攻在哪一档拧 3 圈不裂?
  3. 把结论写成两行:"过孔补偿 = mm,攻丝补偿 = mm",回填进你的参数。
