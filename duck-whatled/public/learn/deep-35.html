解读 35 · 髋关节:pitch 与 roll 的轴线

解读对象:microduck-replica-cad/组件图/02-左髋.png + 03-左髋roll.png + microduck-replica/README.md(关节参数表)
需要的前置:知道"自由度"=一个关节能独立转动的方向数;"轴线"指转动的中心线。

一条腿的根上有三条轴线

每条腿 5 个自由度,前三个全挤在髋部,且三条轴线两两垂直(术语:正交):

  • hip_yaw:绕竖直轴,整条腿像盘腿一样内外摆,行程 −25°~+30°;
  • hip_roll:绕前后向的轴,腿向身体侧面张开/收拢(侧摆),±22°;
  • hip_pitch:绕左右向的轴,腿前后摆——迈步的主运动,±90°。

行程全部出自 README 关节参数表。ID 分配也在这里定型:左腿 20–24 依次为 yaw/roll/pitch/knee/ankle(docs/硬件规格速查.md)。

图上看到的结构

02 号组件图(左髋 yaw→roll):特征树四样东西——固定的 xl330-m288-t1、yaw2roll_偏航转横滚、bearing_roll_轴承滚轮、一个 16×22×4 轴承。图上是一个黑色 L 形支架,侧面装着一个尺寸显眼的轴承——银色内外圈之间一圈滚珠清晰可见——内套一个带 4 个螺丝孔的圆形法兰;支架顶部是蓝色的 XL330,输出端同样是圆形多孔法兰。零件名自带装配逻辑:"偏航转横滚"=这条 L 臂一头接偏航轴、一头接横滚轴。

03 号组件图(左髋 roll):特征树只剩 hip_l_髋部左(固定)加一个 16×22×4 轴承——没有舵机,是纯结构件。图上是一个银灰色 L 形臂,短臂端面开出一圈轴承座(滚珠可见),套住一个带 3 孔的轮毂;长臂末端有圆柱凸台和通孔,留给下一节(大腿)。

两图对照可见"级联":yaw 轴在躯干里(01 号组件的两颗舵机),roll 轴在 yaw→roll 转接件上,pitch 再往下半级。轴线是一条一条叠上去的。

两个设计决定值得琢磨

舵机 + 对顶大轴承。 图上所有转动处都是"一侧舵机输出法兰、另一侧大轴承"的布局。舵机输出轴单点是悬臂受力,腿部侧向力又大;外侧补一个轴承后,弯矩由两点分担,间隙与抖动都变小。代价是零件数和一颗 16×22×4 深沟球轴承——整机 14 颗轴承里的大头(BOM)。

yaw 舵机藏进躯干。 《硬件入门》说躯干内腔"基本被占满",占它的正是两颗 hip_yaw。把执行器往身体中线收是腿式机器人的通用原则:腿的质量绕髋轴产生转动惯量,电机越靠近轴线,摆腿越"轻"、越快,对走路策略也越友好。

你带走的收获

  • 髋部三轴正交布置(yaw 竖直 / roll 前后 / pitch 左右)是双足机器人的标准答案。
  • 转动关节两侧支承(舵机面+轴承)远比单侧悬臂刚,间隙更小。
  • 执行器尽量靠近躯干中线:质量分布比结构强度更影响运动性能。
  • 装配体命名可以自带语义("偏航转横滚"),读特征树比读几何快。
  • 行程范围不对称(−25°/+30°)是真实步态需求,不是设计随意。
