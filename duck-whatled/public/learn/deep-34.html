解读 34 · 躯干主体:装配基准件

解读对象:microduck-replica-cad/组件图/01-躯干主体.png + 01-躯干主体-爆炸图.png(SolidWorks 截图)+ microduck-replica/docs/硬件入门.md
需要的前置:解读 33的反推思路;知道"自由度"=一个关节能独立转动的方向数。

图上有什么

01 号组件图是 SolidWorks 界面截图:一只灰白色壳体以半透明方式显示,像琥珀一样包着里面的东西——能看到一块蓝色 PCB(印刷电路板)横在腔体中部,上面有几个白色接插件和一排排针;底部并排两只黑色舵机,金色的输出法兰朝下,是两颗 XL330。半透明不是艺术效果,是装配图惯用手法:让你看清"壳里装了什么"。

爆炸图更直白,左侧特征树列出这个组件的全部成员:trunk_base(躯干底座)、left_shell/right_shell(左右壳)、两颗 xl330-m288-t1、power_support(电源支架)、电池模型(树里沿用上游命名 np_f970——复刻考据实际是 NP-F550 尺寸,见 BOM 勘误)、两套 16×22×4 轴承、M2铜柱、banana_pcb_locker(香蕉形 PCB 锁扣)和 PCB 模型。躯干主体 199g(README 装配结构),是全机最大的单件。

基准件上承载了什么

机械装配里的"基准件"指装配从哪个零件开始、其余零件都相对它定位。躯干底座 trunk_base 就是这只鸭子的基准件,它身上有四类东西:

  1. 两颗 hip_yaw 舵机——髋偏航(腿绕竖直轴内外转)的执行器固定在躯干内腔,《硬件入门》原话:"内腔基本被占满";
  2. 电路板安装位——图上那块蓝色 PCB 与树里的"蕉形 PCB 锁扣"对应。逆向文档考据:banana_pcb_locker 在整个上游 MJCF 里只出现一次,位置就在 trunk_base(robot_walk.xml:92),装的是把 IMU 伪装成舵机的 imu_to_dxl 板,而且朝向写死——源码常量 DEFAULT_MOUNT 注明"板子装成 trunk = [+raw_z, +raw_y, −raw_x]",装歪了姿态数据整组错位;
  3. 电池——不塞内腔,而是外挂在机身后下方:NP-F550 长 71mm,约 40mm 悬在壳体外,由两片 power_support 从外面夹住;
  4. 左右壳——只包覆外观,不受力。

为什么是它当基准

README 的组件清单写明:躯干主体是"全部组件的装配基准件",15 个组件按 01→15 装,躯干永远第一步。选基准件的逻辑:谁聚合的接口最多、谁最接近整机力学中心,谁当基准。躯干向上接颈根、两侧各接一条五关节的腿、内腔装板子与舵机——它是所有运动链(关节串成的链)的根。基准一歪,后面 14 个组件全跟着歪。

另一个数字值得记住:躯干 199g,头部总成 189g,几乎一样重;整机 737.2g、外形 144×141×264mm。头占四分之一、重心很高——那是解读 38 的主角。

你带走的收获

  • 基准件的选择决定装配顺序:接口最多、最接近力学中心的零件先固定。
  • 承力结构与外观壳体分离(trunk_base 受力、shell 包覆),是小机器人省重省钱的通用做法。
  • IMU 的安装位置与朝向定义整机姿态参考系,是常量不是"装上就行"。
  • 大密度件(电池)外挂 + 支架夹持,既保住内腔空间,又参与整机配重。
  • 看装配体先看特征树:树的成员清单就是这个组件的 BOM。
