解读 76 · 电气适配:插头/线序/调试板

解读对象:docs/macOS舵机调试与图纸查看指南.md §2(总线舵机调试:硬件与供电)
需要的前置:解读 46(电平与转接板)· 解读 66(电池选型)

新舵机到手,第一件事不是装上鸭子,而是在桌面上让它"报上名来"。这一步的全部内容是三件事:
用什么调试板、怎么供电、线序别接反。《macOS 舵机调试指南》(docs/macOS舵机调试与图纸查看指南.md)
§2 把这套流程写成了标准动作,本篇照着走一遍,再补上几家舵机的线序证据。

1. 调试板:按协议家族选,不按型号选

路线 调试板 价格 macOS 软件
Dynamixel 系(XL330 等) ROBOTIS U2D2(建议 + Power Hub 供电) ≈¥200/套 Wizard 2.0 官方 Mac 版
飞特系(STS/SCS/HL) FE-URT-1 或 ¥22–26 第三方 ST/SC 转接板 ¥22–45 图形软件是 Windows 的,见下

飞特没有 Mac 图形软件,指南给了三个替代,按省事排序:①官方 SCServo Python SDK 在 Mac 终端直接跑;
②调试板插树莓派,Mac ssh 过去(和 SG90 台架同一套工作流);③借一台 Windows 笔记本,
用 Feetech 的 FD 软件设完 ID 就还——设 ID 是一次性工作,借一次不亏。

2. 供电与共地:本节最重要的一节

USB 调试板只传数据,不供电。 舵机必须独立供电:1–2 只 XL330 台架用 4×AA 电池盒(6 V)
最简单,或 2S 锂电;Feetech STS/SCS 多数规格 6–8.4 V,按 datasheet 定。

共地铁律:调试板的 GND 必须和舵机电源的 GND 连通。忘了共地 = 扫描不到舵机或乱码,
指南称之为新手第一大故障——概念上就一句话:电流要有一个回家的回路,信号才有一个统一的"0V 参考点"。

上电顺序也是铁律:接完线 → 万用表通断档确认电源正负没短路 → 先给舵机上电,再插 USB;
改任何线之前断电。另外 macOS 自带 screen 命令波特率上限不够,1 Mbps 总线调试一律用
Wizard 或 Python(pyserial 支持 1 Mbps)。

3. 线序:一插反就烧,两份文档还会打架

线序是电气适配里唯一"错了就报销"的地方,各家舵机不相同:

舵机 插头 线序 出处
XL330 Dynamixel 3-pin JST 1=GND 2=Vcc 3=Signal 逆向文档五之二
HL-2915-C001 PH1.25-3P(1.25 mm 间距,与 5264/JST-EH 不通用) 1=GND 2=Vcc 3=Signal 《HL-2915-C001 规格书》
HD-1910-C001 AMP-3P ⚠️ 两份文档说法相反 见下

⚠️ HD-1910 的线序存在文档冲突:《硬件方案逆向》(microduck-replica/docs/硬件方案逆向.md)
写 1=GND / 2=Vcc / 3=Signal;而 《HL-2915 路线全流程教程》(docs/HL-2915路线全流程教程.md) §9.2
写"脚序与 HL 相反:1=Signal / 2=Vcc / 3=GND"。两个来源只能信一个,处理方式只有一个:
到手先拿规格书 + 万用表实测确认,再插电。这正是"线序必须逐只核对"的活教材——
文档会打架,实物不会。

4. 扫不到舵机?按这个顺序查

指南 §7 的排查表浓缩成一句口诀:先电源、再共地、后波特率、最后 ID——
① 舵机电源独立供了吗 ② 共地了吗 ③ 波特率勾对了吗(新舵机出厂可能是 57600,设过的才是 1M)
④ 总线上是不是挂了两只同 ID 的舵机(两只出厂都是 ID=1)⑤ 数据线插反没。
拧螺丝装上鸭子之前,这五问全过,电气适配就算交卷。

你带走的收获

  • 调试板按协议家族选:U2D2 对 Dynamixel,FE-URT-1 对飞特;Mac 没图形软件就用 Python SDK 或借 Windows。
  • USB 调试板不供电;独立电源 + 共地是台架第一课,"扫不到"九成出在这两处。
  • 上电顺序:查短路 → 舵机上电 → 插 USB;改线必先断电。
  • 线序是唯一烧硬件的错误,而且文档之间可能互相矛盾——以实物实测为准,别信任何一个单一来源。
  • 排查顺序固定:电源→共地→波特率→ID 冲突→插反,从便宜到昂贵的假设逐个排除。
